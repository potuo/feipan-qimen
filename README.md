飞盘奇门排盘是一款遵循《奇门基础资料 2023版教》口径的奇门遁甲排盘工具。与市面上常见的转盘奇门不同，本 App 采用**飞盘（鸣法）体系**：九星八门按洛书宫序顺飞、天禽居中宫、符使可入中，并严格实现「值使门飞宫法」与「符头地支定元」。

## 🧮 排盘算法（据《奇门基础资料 2023版教》）

### 核心规则（飞盘 vs 转盘的根本差异）

| 项目 | 转盘（普通奇门） | **本 App（飞盘）** |
|---|---|---|
| 天禽星 | 寄坤二宫 | **居中宫，随局更使** |
| 九星/八门 | 随值符旋转 | **按洛书宫序顺飞**（阴阳遁皆顺飞） |
| 八门 | 八门 | **九门**（多一「中门」居中宫） |
| 值符/值使 | 不入中宫 | **可入中宫** |
| 八神 | 八神 | **九神**（多「太常」，另白虎藏勾陈、玄武藏朱雀） |

### 排盘七步

1. **排四柱**：立春分年、节令分月、子时分日；五虎遁起月、五鼠遁起时
2. **定局**：冬至后阳遁/夏至后阴遁；**符头地支定元**（甲/己日为符头，子午卯酉上元、寅申巳亥中元、辰戌丑未下元），查节气局数表
3. **布地盘奇仪**：戊己庚辛壬癸丁丙乙，阳顺阴逆布洛书九宫
4. **布天盘奇仪**：值符干（旬首遁仪）加地盘时干宫，奇仪整体平移
5. **布九神**：值符螣蛇太阴六合勾陈太常朱雀九地九天，阳顺阴逆
6. **布九星八门（飞盘核心）**：
   - 值符星 = 旬首遁仪宫本位星，加时干宫后**顺飞**
   - **值使门 = 从旬首宫按六十甲子序数阳顺阴逆数到当前时辰（飞宫法）**
   - 天禽固定中宫、中门固定中宫
7. **布暗干支**：时干支加值使宫，飞宫法顺逆排布；空亡不排、遇甲不排

### 校验案例

- **2026-08-17 22:00**（癸亥时，阴遁八局）：旬首甲寅遁癸落震3 → 值使伤门落震3 ✓
- **2025-10-22 卯时**（丁卯时，阴遁六局）：旬首甲子遁戊落乾6 → 值使开门落震3 ✓
- **2024-12-03 9:19**（癸巳时，阴遁八局）：值使开门落乾6 ✓

## 🛠️ 技术栈

- **Kotlin + Jetpack Compose**（Material 3，单 Activity 架构）
- **Room**（案例本地数据库，LIKE 即时搜索）
- **Gson**（盘面序列化 / JSON 导入导出）
- **[cn.6tail:lunar](https://6tail.cn)**（农历/干支/节气/黄历历法引擎）
- minSdk 26 / targetSdk 34 / compileSdk 34
- Gradle 9.7 / AGP 9.3 / JDK 17+

## 📁 项目结构

```
app/src/main/java/com/potuo/feipanqimen2/
├── MainActivity.kt          # 单 Activity：侧滑栏框架 + 启动动画 + 主题管理
├── qimen/
│   ├── QimenCalculator.kt   # 飞盘排盘核心算法（纯 Kotlin，可单测）
│   ├── QimenModels.kt       # 数据模型（九宫/盘面/四柱）
│   ├── QimenConstants.kt    # 星/门/神/奇仪/局数表常量
│   └── HuangLiService.kt    # 黄历数据服务（lunar 库封装）
├── data/                    # Room 实体/Dao/仓库 + 导入导出
├── log/LogManager.kt        # 应用日志系统（按天滚动 + 崩溃捕获）
├── ui/
│   ├── InputScreen.kt       # 排盘输入页（日期+十二时辰+备注）
│   ├── ResultScreen.kt      # 盘面结果页（九宫+黄历+保存案例）
│   ├── HuangLiScreen.kt     # 黄历详情页
│   ├── CaseListScreen.kt    # 案例库（双列卡片墙+搜索）
│   ├── CaseDetailScreen.kt  # 案例详情（编辑/导出/删除）
│   ├── SettingsScreen.kt    # 设置（折叠分组：外观/数据/日志/更新）
│   └── components/          # 盘面/黄历卡/通用组件
└── viewmodel/MainViewModel.kt
```

## 🏗️ 构建与安装

```bash
# 环境：JDK 17+、Android SDK（compileSdk 34）
./gradlew test          # 运行算法单元测试（含排盘校验案例）
./gradlew assembleDebug # 构建 Debug APK
# 产物：app/build/outputs/apk/debug/app-debug.apk

# 安装到已连接设备
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
