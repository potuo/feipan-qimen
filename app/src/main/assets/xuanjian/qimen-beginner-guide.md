# 奇门初学者 · 看盘思路引导（不断盘）

> 本资料面向奇门初学者：**不直接给出吉凶结论，只引导你「怎么想、从哪看、看什么」**。
> 目标是教你独立看懂一个飞盘奇门盘，形成自己的判断思路。具体排盘规则与格局知识见「飞盘奇门规格」。

## 一句话原则

盘是「信息」，不是「答案」。看盘 = 把盘面信息翻译成「所问之事的线索」，结论由你自己下。

## 看盘四步（思路框架）

### 第一步 · 看全局（这是个什么盘）
- 先看清：阴阳遁、局数、节气、四柱、空亡——搞清「这是一个什么盘」。
- 找到值符星、值使门的位置——这是全盘的「主角」与「事之中枢」，先记住它俩在哪。

### 第二步 · 定用神（所问之事看哪里）
- 先想清楚你问的是什么，再去盘里找对应的位置。用神定不准，后面全白看。
- 常见对应（更多见「飞盘奇门规格」§6 分类占断）：
  - 问财 → 生门、戊（资本）
  - 问病 → 天芮（病星）、生门（生机）
  - 问婚姻 → 乙、庚、六合
  - 问考试 → 天辅、景门
  - 问出行 → 所去方向之宫、马星
  - 问失物 → 所失之物落宫
- 自问一句：这事在盘里「应该」对应谁？

### 第三步 · 看用神宫（吉凶的根据）
看用神所在宫，逐项问自己：
- **旺衰**：用神现在旺相还是休囚？（旺 = 有力，衰 = 无力）
- **生克**：用神宫与「时干（你/所测事）」宫是什么关系？生我？克我？比和？
- **格局**：这宫有没有触发格局？（如击刑、入墓、门迫、空亡）
- **星门神**：这宫落的星/门/神，象意符不符合所问之事？

### 第四步 · 综合印证（别急着下结论）
- 一个象不算数，多个宫、多个格局「同向指向」时才可信。
- 有矛盾象时如实摆出来，别只挑吉的或只挑凶的。
- 空亡、入墓、门迫这些「特殊状态」优先看——往往是最关键的信息。

## 新手常踩的坑（提醒，不是答案）
- 不要「看到凶星就慌」：吉凶看旺衰、生克、格局的组合，单看一个符号会误判。
- 不要「先有结论再找证据」：先客观看盘，再形成判断。
- 不要「一个字面意思硬套」：星门神是「象」，要结合所问之事去理解。
- 空亡 = 事虚或未成，别当「已经发生」来断。

## 边界声明
- 本资料只提供「思路」，不提供「结论」。具体吉凶请结合「飞盘奇门规格」的排盘与格局知识自行判断。
- 奇门是传统数术，结果仅供参考，最终判断在你。
